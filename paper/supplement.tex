\section{Prompt template}
The TREC prompt for $k=2$ is shown below; Emotion and DBpedia-14 use ``Text:'' instead of
``Question:'' and their own instruction and label list. Demonstrations appear from least to most
similar.
\begin{quote}\footnotesize\ttfamily
Classify each question by the type of answer it asks for. Use exactly one of these labels:
abbreviation, entity, description, human, location, number. Reply with the label word only.\\[2pt]
Question: \textit{(second most similar pool question)}\\
Answer: \textit{(its label)}\\[2pt]
Question: \textit{(most similar pool question)}\\
Answer: \textit{(its label)}\\[2pt]
Question: \textit{(test question)}\\
Answer:
\end{quote}

\section{Preregistered comparison families}
Primary (Holm within family): S7--S5, S7--S3. Secondary: S7--S2, S7--S13. Exploratory: S8--S5,
S12--S11, S15--S2, S16--S17, S16--S7. The oracle S14 is never tested; it is reported only as a bound.
Everything else (NCA runs with 6--12 qubits, Banking77, 2{,}000-item test sets, $k$ sweep, order,
bandwidth study, robustness, difficulty strata) is exploratory and uncorrected. The TOST margin and
all selector settings above were fixed in the same dated file as the decision rules.
